# Homestead Scholar

My record of working through *The Homestead Scholar* — an integrated programme in
mathematics, reasoning and total self-reliance. Vault of everything I make:
maths notebooks, philosophy essays, research experiments, builds, and grades.

## Structure
- `ledger/`   structured records (progress, benchmarks, books, skills, builds, software)
- `modules/`  one folder per 8-week module (m01…m17): maths, essays, research, builds, log, grade
- `maths-lab/` the running Jupyter notebook + Project Euler solutions (1–100 public)
- `datasets/` longitudinal field data (compost, soil, energy, bamboo…)
- `journal/`  weekly Friday entries
- `notes/`    Obsidian vault (reading notes / Zettelkasten)
- `media/`    photos/drawings (or referenced from cloud storage)
- `private/`  Euler 101+, anything unpublished (gitignored)

## Rhythm
- **Every Friday (Studio):** commit the week's work + add a `journal/` entry.
- **End of each module:** fill in `modules/mXX/grade.md`, update the `ledger/` files.

See `SETUP.md` for the one-time environment setup.
