# Module 1 — The Maker's Foundation: Day-by-Day

*Open this file each morning. It's the full handbook (readings, apps, sub-topics)*
*already resolved down to "what do I actually do today" — you shouldn't need to*
*go back to the PDF during the module itself.*

## Before Day 1 (once)

- Accounts: Project Euler, Khan Academy, Corbettmaths, Dr Frost Maths, Maths Genie,
  Anki (+ AnkiWeb + AnkiDroid). iNaturalist can be registered now too, but its
  first real use isn't until Module 4 — no need to touch it yet.
- `conda env create -f environment.yml` → `conda activate scholar` → `nbstripout --install`.
- VS Code: install the Python + Jupyter extensions, open `maths-lab/lab.ipynb`,
  pick the `scholar` kernel, confirm it runs.
- Obsidian: open this repo's `notes/` folder as a vault.
- Gather mallet/sawbench timber, hand-tool starter kit, pot-garden containers
  (see the handbook's Module 1 "Equipment & Materials" table for the KES ranges).
- Book a first-aid course (Kenya Red Cross / St John Ambulance Kenya) now — you
  won't sit it until roughly Week 6, but booking is a Week-1 task.

## Standing daily rituals (every Session 1, every day)

- **10 min warm-up:** Corbettmaths "5-a-day" (Foundation).
- **Last 5 min:** one Anki review pass ("Homestead Scholar" deck — you'll start
  adding cards to it from Friday's philosophy sessions onward).

## How to log

- Tick the checkbox below as you finish each day.
- Each **Friday = Studio**: write 2-4 lines per strand into that week's
  `journal/2026-Wxx.md` (already templated — Week 1 = W31, ... Week 8 = W38).
- End of the module: fill in `modules/m01/log.md` (one line per week) and
  `modules/m01/grade.md` (the six artifacts + your self-review).

Site references below say **Voi** — that's the terrace/rooftop garden at home base.
